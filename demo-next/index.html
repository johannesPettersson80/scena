A scene is data, so anything can write one.

Scenes are a versioned, validated JSON contract. Hand it to a person, a build step, or a language model — then render it from the command line and check the result. 

$ scena examples agent get product-configurator --out ./scene
$ scena recipe render ./scene/recipe.json --out shot.png
