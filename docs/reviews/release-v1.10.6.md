# scena 1.10.6 release review

This patch release fixes imported glTF line primitives and the v1.10.5 package
omission that broke `cargo install scena --features agent`. It is accepted only
when focused line-import and mixed-CAD proofs pass, an extracted package installs
and reports the agent feature, the isolated remote release rehearsal passes, and
the public tag, GitHub release, crates.io archive, and docs.rs agree on one source
commit.
