# scena 1.12.0

Equirectangular environments face the same way as in three.js, and the CPU
renderer reflects them sharply on glossy surfaces.

Rendered output changes for scenes lit by an equirectangular HDR, the bundled
`Studio` preset among them, and for smooth untextured materials on the CPU
renderer; see the 1.12.0 section of `CHANGELOG.md` for details.

- Map equirectangular HDR environments as three.js, model-viewer and the
  Khronos glTF Sample Viewer do, with the centre of the image along +X. scena
  previously turned every equirectangular environment 90 degrees about +Y. To
  keep an earlier look, add 90 degrees to the environment's Y rotation;
  photographic auto-lighting keeps its placement relative to the camera.
- Move environment prefilter sidecars to format version 3. A version 2
  `.prefilter.bin` is rejected with a warning and rebaked at load; regenerate
  it with `cargo run -p xtask -- prerender-environment <input.hdr>`.
- Subdivide glossy CPU-shaded triangles on screen, so chrome and other smooth
  untextured surfaces reflect the environment and their highlights along the
  surface instead of the tessellation.
