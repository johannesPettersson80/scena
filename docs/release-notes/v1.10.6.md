# scena 1.10.6

Reliable glTF line rendering and fail-closed packaged agent installation.

- Import glTF line primitives as line geometry without requiring triangle
  normals and preserve their base color in a generated line material.
- Preserve authored line materials when applying CAD viewport styling to mixed
  triangle and line assets, without adding invalid line-edge overlays.
- Package the final photo policy used by the agent CLI and validate the real
  extracted `.crate` with the documented `agent` feature before publication.
- Enforce the packaged-install gate in CI, release workflows, local readiness,
  publish rehearsal, and `xtask doctor --full`.
- Reduce the built-in CAD viewport edge core from 1.25 px to 1.0 px so
  anti-aliased feature rings remain crisp and subtle. The renderer keeps the
  width constant in screen space and continues suppressing smooth cylinder
  side facets.
