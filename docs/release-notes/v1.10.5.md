# scena 1.10.5

Typed host-owned clipping planes for native and browser scene hosts.

- Add `SceneHostCore::set_clipping_planes_json` and the browser
  `SceneHost.setClippingPlanesJson` binding.
- Replace or clear an arbitrary host-owned set of clipping planes through a
  stable versioned JSON contract without exposing renderer handles.
- Validate complete updates before mutating host state, so invalid requests do
  not partially replace the active plane set.
- Cover replacement, rejection, clearing, normalized responses, schema
  cataloging, browser bindings, and doctor enforcement.
