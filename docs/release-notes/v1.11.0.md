# scena 1.11.0

Path-traced stills, one layered surface model on CPU and GPU, exact
world-matrix placement, and hardened glTF import.

Rendered output changes for layered materials, image-based lighting, shadows,
bloom, FXAA and glass; see the 1.11.0 section of `CHANGELOG.md` for the full
list and what to expect.

- Add path-traced stills: `Renderer::path_trace` renders the scene on the CPU
  with surface finishes and rounded edges, and `scena photo render
  --path-trace` delivers photos from it.
- Rework shading around one layered surface model shared by the native,
  WebGL2 and CPU renderers: clearcoat, sheen, anisotropy, iridescence and
  IOR-dependent reflectance are layers of the base surface, not added lobes.
- Directional diffuse environment lighting, soft cascaded directional shadows,
  screen-space ambient occlusion, per-pixel alpha masking, edge-search FXAA,
  separable Gaussian bloom, and physically composed glass.
- Resolve world transforms as affine matrices and place lights, connections,
  placement verbs and instances by exact world matrices. Add `PlacementFrame`
  and `Scene::placement_frame`.
- Keep prepared scenes and retained GPU resources across camera moves, and
  make retained draws follow their nodes.
- Harden glTF import against malformed and hostile files, bound the memory an
  import materializes, and import strips, fans, line strips, line loops,
  percent-encoded URIs, lights on mesh nodes and surface finishes.
- Add `Tonemapper::tone_map` and a flanged gate valve demo model.
