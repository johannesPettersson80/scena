# scena 1.10.3

Browser startup and renderer-readback correctness follow-up.

- Compile only the material pipelines required by the prepared browser scene,
  and avoid depth, transmission, or duplicate readback resources when the
  frame does not use them.
- Reset WebGL2 pixel-pack state before canvas `readPixels`, fixing zero-filled
  browser validation after WGPU leaves a pack buffer bound.
- Use byte-target overlay pipelines for independent browser readback so labels
  and strokes match the attachment format on WebGPU and WebGL2.
- Emit staged preparation, frame, allocation, and browser workflow timings for
  actionable diagnosis of renderer startup or lifecycle stalls.
- Present attached browser frames without an implicit renderer-owned readback;
  browser proof and recovery paths request capture explicitly and use a bounded
  WebGPU queue-completion wait before rebuilding a lost device.
- Capture deployed-demo evidence from Chromium's compositor, report the actual
  browser GPU, and gate the imported-photo camera behavior in CI and release.
- Move browser camera-control handling into its own owner module and extend
  deterministic lifecycle coverage for the reduced allocation contract.
