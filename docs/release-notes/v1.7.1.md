# scena 1.7.1

Release date: 2026-06-12

## Fixes

- The WaterBottle CPU release proof now renders at the default 512x512
  artifact size instead of running a 4x supersampled software render inside
  every `cargo test`. The proof still imports the real Khronos WaterBottle
  glTF, checks prepared material/texture topology, asserts sampled material
  colours, validates colour-family histograms, verifies the warm studio
  background, and writes the CPU PNG artifact.
- This keeps the release evidence meaningful while preventing GitHub hosted
  Linux CI from killing the native/headless job after a long no-output CPU
  render.
