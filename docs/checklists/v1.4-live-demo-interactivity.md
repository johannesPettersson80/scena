# v1.4 live demo interactivity

Status: historical v1.4 demo checklist. Completed rows record what shipped for
that release; deferred rows now belong in the current easy-use roadmap if they
are still relevant.

Goal: the `scena-demo.pages.dev` page must let a visitor **actually use** the
v1.4 surface in their browser, not just read a code snippet about it.
Items below were the deployed-demo gaps at the time this checklist was written
and the work this checklist delivered.

## Status legend

- **[shipped]** — bound + UI + tested in headless browser locally
- **[in-progress]** — implementation underway
- **[gap]** — not started

## Out of scope for this checklist

- `<scena-viewer>` custom element on the demo page (separate bet; element is shipped through the library and ready for host adoption but rendering parity with `<model-viewer>` is still in progress; not the way to demonstrate v1.4 named presets)
- Hot reload demo (filesystem watcher is native-only; browser doesn't have it)
- Display P3 wide-gamut canvas configuration (browser canvas color-space switch is non-trivial UI; deferred to a follow-up)
- Material-extension visible proof (clearcoat / sheen / iridescence / dispersion / transmission lobes — the M6 browser proof on real-GPU CI is the proof venue)
